# 1. Overview

This document defines the major development milestones of the project.

Each milestone represents a significant achievement that moves the project closer to release.

Unlike Sprint documents, milestones focus on completed features and development goals rather than individual implementation tasks.

---

# 2. Milestone Philosophy

Every milestone should:

- Deliver measurable progress.
- Produce a stable and playable build.
- Be independently testable.
- Build upon previous milestones.
- Support the long-term project vision.

Milestones should represent meaningful development achievements rather than collections of unrelated tasks.

---

# 11. Milestone Completion Criteria

A milestone is considered complete only when:

- All planned deliverables are finished.
- The project builds successfully.
- Gameplay is fully testable.
- Critical bugs are resolved.
- Documentation is updated.
- The project remains stable.
