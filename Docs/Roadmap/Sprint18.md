# 1. Overview

Sprint 18 represents the official Version 1.0 release of the game.

This sprint is focused on final packaging, deployment preparation, documentation finalization, and ensuring the product is ready for public distribution.

No gameplay changes or system modifications are allowed.

This is the end of active development.

---

# 2. Sprint Objective

Deliver a complete, stable, and release-ready version of the game.

At the end of this sprint the project should support:

- Final build ready for distribution
- Stable and verified gameplay experience
- Complete documentation package
- Final configuration and settings
- Verified performance and stability
- Release-ready assets and content

# 4. Release Scope

## Included Systems

- Full gameplay loop
- UI Framework
- Audio System
- VFX System
- Fog of War
- Save/Load System
- Balanced gameplay (Sprint 13)
- Optimized systems (Sprint 14)
- Fully integrated Vertical Slice (Sprint 15)

---

## Frozen Content

The following are fully locked:

- Gameplay mechanics
- Balance values
- System architecture
- UI structure
- Save format
- Audio/VFX structure

Only critical bug fixes are allowed during final verification.

# 5. Release Preparation Tasks

Complete the following work:

- Create final production build
- Remove all debug and development tools
- Verify all systems in release configuration
- Finalize version number (v1.0.0)
- Prepare release notes
- Validate all documentation
- Ensure all assets are included in build
- Run final full playthrough
- Confirm no critical issues remain
