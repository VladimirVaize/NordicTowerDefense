# 1. Vision Statement

Hrafnar is a modern strategy-focused Tower Defense game inspired by Scandinavian landscapes, thoughtful planning, and meaningful player decisions.

The project aims to create a gameplay experience where strategy is driven by systems rather than scripted events. Every decision should have a lasting impact on the battlefield, encouraging players to analyze, adapt and optimize their defenses.

The game should reward planning, experimentation and tactical thinking instead of relying on fast reactions alone.

# 3. Core Design Pillars

The project is built around five fundamental design pillars.

---

## Strategic Depth

Players should solve problems through planning and positioning rather than mechanical execution.

Every tower, building and resource should contribute to meaningful strategic choices.

---

## System-Driven Gameplay

Gameplay should emerge from the interaction of independent systems.

Examples include:

- Resource economy
- Building placement
- Tower coverage
- Enemy behavior
- Wave generation
- Fog of War

These systems should complement one another without relying on hardcoded scenarios.

---

## Readability

Information should always be presented clearly.

Players must easily understand:

- Enemy threats
- Tower ranges
- Building influence
- Resource locations
- Wave progression

Good readability supports better decision-making.

---

## Meaningful Progression

Progression should unlock new tactical possibilities rather than simply increasing numerical values.

Examples:

- New building types
- Additional tower mechanics
- Expanded strategic options
- Improved resource management

---

## Scalability

Every gameplay system should be designed for future expansion.

New content should integrate into the existing architecture without requiring major redesigns.

---

# 4. Target Audience

The game is intended for players who enjoy:

- Strategy games
- Tower Defense games
- Optimization
- Base building
- Resource management
- Tactical decision-making

The design should appeal to both newcomers and experienced strategy players through intuitive mechanics with increasing depth.

---

# 5. Gameplay Experience

The intended player experience can be summarized as follows:

- Explore the map.
- Secure valuable resources.
- Expand the settlement.
- Build an efficient defense network.
- Adapt to changing enemy threats.
- Continuously improve strategic decisions.

Every match should encourage learning and experimentation.

---

# 6. Artistic Vision

The visual direction is based on a stylized Scandinavian aesthetic.

Key characteristics include:

- Low-poly 3D assets
- Clean silhouettes
- Readable environments
- Natural Nordic color palette
- Hand-painted textures
- Consistent asset scale

The art style should prioritize gameplay readability while creating a calm and immersive atmosphere.

---

# 7. Technical Vision

The project should be built using a modular, maintainable and scalable architecture.

Key principles include:

- Feature-based architecture
- Data-driven design
- ScriptableObjects for configuration
- Event-driven communication
- Decoupled gameplay systems
- Consistent coding standards

The codebase should remain understandable and easy to extend throughout the project's lifetime.

---

# 8. Long-Term Goals

The project is designed with long-term development in mind.

Potential future additions include:

- New biomes
- Additional enemy factions
- New tower families
- Advanced buildings
- Hero units
- Endless mode
- Challenge modes
- Difficulty modifiers
- Seasonal content
- Post-launch updates

The architecture should support these additions without significant refactoring.

---

# 9. Success Criteria

The project will be considered successful if it achieves the following goals:

- Stable and maintainable codebase
- Clear and consistent documentation
- Readable and enjoyable gameplay
- Strong strategic depth
- Expandable architecture
- Cohesive visual identity
- Smooth development workflow

Success is measured not only by the final game but also by the quality and sustainability of the development process.
