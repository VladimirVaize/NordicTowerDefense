# Nordic Tower Defense

> A stylized Scandinavian-inspired 3D Tower Defense game built with Unity.

---

## Overview

**Nordic Tower Defense** is a long-term game development project focused on creating a polished and scalable Tower Defense experience inspired by Scandinavian landscapes and mythology.

The project is built with a strong emphasis on:

* Clean software architecture
* Modular gameplay systems
* Professional documentation
* Maintainable codebase
* Scalable production workflow

Rather than focusing solely on gameplay implementation, the project follows a production-oriented development process similar to those used in professional game studios.

---

# Project Goals

The primary goals of this project are:

* Build a modern Tower Defense game using Unity
* Develop a clean and extensible architecture
* Maintain high coding standards
* Document every major system
* Support long-term development
* Enable efficient team collaboration
